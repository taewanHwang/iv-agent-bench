# 원자료와 공유 범위

**공유 수준: 요약만 제공. 원문 데이터 업로드 없음.** 저장소가 비공개여도 개인 원자료를 이곳에 넣지 않는다.

[raw-manifest-v1.json](raw-manifest-v1.json)은 원본 입력·요청·답변·Hermes DB에서 가져온 trajectory·판정 자료의 크기, 바이트 SHA-256, 로컬 저장 위치를 기록한다. `local_path`는 소유자 컴퓨터의 저장 위치이지 GitHub 다운로드 링크가 아니다. DB 자체·인증 파일은 공유하지 않는다.

| 자료 | GitHub에서 제공 | 로컬 비공개 |
|---|---|---|
| 실험 목적·범위·환경 | experiment.json·보고서 | — |
| 시간·토큰·호출 측정 | 집계 JSON | 원본 응답·요청 로그 |
| 품질 평가 | rubric·요약 finding·이벤트 ID | 판정 packet·메일/일정과 답변 전문 |
| 원자료 연결 | 파일 목록·해시·로컬 위치 | 고정 스냅샷·개별 trajectory·답변 |
| 하네스 | 실행 조건과 한계 설명 | 당시 worker 소스 스냅샷 |

`hermes-message-1`은 해당 run의 입력, `hermes-message-2`는 출력이다. `mail-NNN`/`calendar-NNN`은 비공개 입력 내부 식별자다. 인용 ID의 존재와 원자료 해시만으로 주장 정확성을 독립 검증할 수는 없다.

공유 자료만으로 검토할 수 있는 것은 집계 산술, 버전 연결과 판정 방식이다. 원문에 대한 품질 판정 재현에는 소유자의 별도 접근 승인이 필요하다. 원문 공개가 허용되지 않으면 합성 사례나 사람이 검토한 발췌를 별도 데이터 revision으로 추가해야 하며, 원문과 동일한 재현성을 주장하지 않는다.
