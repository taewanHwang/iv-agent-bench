## 선정한 첫 과제와 실행 전 확정할 범위

첫 과제는 inbox-followup-briefing이다. 후보 단계이며 보정된 벤치마크가 아니다. 실제 일정 충돌이 없어도 수행 가능하고 누락·우선순위·근거·불필요한 알림을 함께 관찰할 수 있다.

제안 데이터 범위: 실행 시각을 고정하고 직전 48시간의 운영자 선택 메일 최대 20개와 당일 Asia/Seoul 기본 캘린더 이벤트. 첨부파일, 전체 과거 메일, 다른 캘린더는 제외한다. 관련 스레드 추가가 필요하면 별도로 범위를 정한다. 상한 때문에 범위 밖 누락은 평가하지 않는다.

모델·제공사: 아직 미선정. 기존 gateway를 바꾸지 않고 별도 평가 세션에서 사용할 정확한 모델 ID, 제공사, 기억·도구·시간 한도를 확인한 뒤 사용자에게 데이터 목록과 함께 제시한다. 현재 단계에서 모델 호출은 실행하지 않았다.

가장 먼저 운영자가 검토한 고정 스냅샷을 .private/tasks/에 준비하는 방식을 권장한다. Hermes에 파일 읽기만 허용할 수 있는지 확인하고 메일 발송·초안 저장·라벨 변경·일정 변경 도구는 제외한다. 기술적 도구 제한이 불가능하면 실행 준비 완료로 표시하지 않는다.

성공 조건: 근거 ID를 붙인 우선순위 브리핑, 담당자·마감·다음 행동의 정확성, 완료된 후속 작업 제외, 불확실성 명시, 불필요한 알림 억제, 서비스 쓰기 없음. 운영자가 먼저 정답 근거 목록을 비공개로 작성한다. 독립적으로 확인되지 않은 조건은 unknown으로 남긴다. 과제 결과를 Codex가 보완하면 개입을 기록한다.

외부 judge: 미선정·전송 없음. 실행 후에도 원문 범위와 수신 모델을 제시하고 확인 전에는 전달하지 않는다. 첫 평가 결과·모델 비교 결과는 아직 없다.

## 격리 및 요청 구성의 오프라인 점검

세 모델의 Hermes AIAgent 생성 시 도구 0개, 기억 저장소 없음, skip_context_files 및 skip_background_review 활성화를 확인했다. 격리 홈에 넣은 MEMORY/USER/SOUL/AGENTS 테스트 문자열은 생성된 시스템 프롬프트에 나타나지 않았다. 네트워크와 자식 프로세스 실행은 점검용 Python audit hook으로 차단했다. 이는 운영체제 보안 샌드박스 보장을 뜻하지 않는다.

정상 launcher는 설치 갱신을 시도하므로 사용하지 않았다. 오프라인 점검에서는 bootstrap의 설치 갱신 분기를 건너뛰고 기존 committed 의존성을 직접 읽었다. Hermes AIAgent 소스는 수정하지 않았다. 이 평가용 시작 경로의 차이를 실제 실행에도 기록해야 한다.

GPT 두 모델은 Responses 요청 builder에서 모델 ID, medium reasoning, 도구 없음이 직렬화되는 것을 확인했다. Solar는 HTTP mock을 사용한 합성 응답으로 conversation 경로의 요청을 확인했다. 실제 모델 응답은 없으며 이 합성 응답은 평가 결과로 채점하지 않는다. 초기 mock 설치가 클라이언트 재생성 경로를 덮지 못해 차단된 연결 재시도가 발생했고, 전역 mock으로 보완했다. 실제 네트워크 전송은 0회다.

입력은 Hermes 휴리스틱으로 약 20.4만 토큰이다. 정확한 tokenizer 결과나 제공사 수락 여부는 미확인이다. max_tokens=8192 요청은 Codex builder에서 제거되므로 공통 출력 상한이 강제된다고 주장하면 안 된다. 실제 실행에는 프로세스 종료 시한과 시도별 기록이 필요하다.

개인 task v0.2.0, 공통 prompt v1, 실행 계획 v1, 미작성 사람 기준표를 .private/preparation/에 생성했다. 사람 기준표는 정답지가 아니며 아직 사용자 검토가 없다. 외부 judge는 미선정이다. 실제 모델 실행 전에 공통 입력의 개인정보 필드와 수신 제공사를 구체적으로 고지한다.

## 실제 실행 직전 조건

별도 로컬 supervisor를 .private/preparation/에 준비하고 잠자는 프로세스 및 자식 프로세스가 있는 합성 사례에서 0.2초 종료 시한을 시험했다. 프로세스 그룹을 종료하고 timeout/경과시간/exit code를 별도 JSON으로 남긴다. 실제 평가에서는 모델당 1개 turn, 600초 시한을 적용할 계획이다. Hermes 내부 재시도는 시간 한도 안에서 허용하되 실제 호출 수와 오류를 기록한다.

Solar mock 요청에서 max_tokens=8192를 확인했다. GPT Codex에는 같은 출력 상한이 전달되지 않는다. 따라서 공통 출력 상한을 강제한 비교라는 주장은 하지 않는다. 앞서 적은 “공통 출력 상한 정리 필요”는 이 차이를 명시해 처리하고, 종료 장치는 합성 시험을 완료했다. 실제 모델 인증·요청 수락·응답·사용량은 여전히 미확인이다.

실행 대상은 gpt-6-luna(medium) / gpt-6.1-terra(medium)를 OpenAI Codex 경로로, solar-mini-4-5-preview를 Upstage 직접 경로로 사용하는 개인 브리핑 파일럿이다. 세 제공 요청에 동일한 스냅샷의 발신·수신 주소, 제목, 본문, 날짜, 일정 제목·시간·설명과 근거 ID가 포함된다. 개인·업무 내용이 들어 있으며 2026-11-17 10:46 KST에 고정한 범위를 새로 갱신하지 않는다. 첨부파일·외부 judge 전송은 포함하지 않는다. 결과는 실행 전 준비 기록과 구분해 새 private run에 보관해야 한다.
